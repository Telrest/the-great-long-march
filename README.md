# 长征模拟器

[在线体验](https://telrest.github.io/the-great-long-march/)

双击 `index.html` 即可离线游览。先展开长征路线总览，再沿着地图进入主线。全程有 18 页、4 章和 6 个双选场景，从中央苏区讲到 1936 年三大主力胜利会师。

## 阅读与选择

- 箭头沿行军示意路线推进。抵达节点后，路线旁的插画卡展开，进入历史情境画面。左侧以历史插画开场，每隔五秒循环播放资料照片及局部镜头，可暂停或用箭头手动切换。右侧正文背景随当前配图切换。
- 普通话旁白从路线总览覆盖到六页尾声，包含场景正文、选项和结果。在选择页可边听边作答，答错先播放一段原创警示音。
- 调试时可拖动或点击顶部进度条直达任意一幕，立即显示正文和选项。聚焦进度条也可用方向键切换。
- 可开关旁白、跳过过场或立即显示全文。进入具体场景后，点「看路线」可查看已经走过的路线。地图支持鼠标拖动、滚轮和双指缩放，并可点「全程」复位。
- 互动页把线索放在正文旁。选择后进入历史回看或独立的推演画面。推演读完后可返回同一题重选。
- 四渡赤水按日期呈现渡河方向，再给一次双选判断。夹金山和过草地的具体抉择以情境方式呈现。
- 完成图文页或进入历史回看后，可展开「史料出处」。画面下方标明插画和资料照片，资料照片附作者及许可证。
- 胜利会师后可打开[央视新闻纪念短片《万里长风》](https://www.bilibili.com/video/BV1LrJR6aEh6/)，然后回到原页面进入「长征的伟大意义」。可手动翻阅六页正文或重听旁白。末页点「再次品味」回到开篇。

## 编辑和预览

- `js/data.js` 保存章节、文案、选项、推演和史料链接。
- `js/journey-data.js` 保存示意路线和节点。`js/journey.js` 绘制地图、箭头及镜头运动。
- 正文插画和局部镜头配置在 `js/data.js`。资料照片和来源索引见 `assets/photo/` 与 `js/photos.js`。
- `js/app.js` 控制单页播放、旁白、选择分支和翻页。离线旁白及答错音效位于 `assets/narration/`，旁白采用普通话神经男声云健。
- `css/style.css` 控制桌面及手机排版，插画位于 `assets/img/`。
- 可在地址末尾添加 `?scene=xiangjiang`、`?scene=liping` 或 `?scene=jiajin` 直接预览对应页面。
